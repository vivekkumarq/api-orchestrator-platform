# Screenshots

`api-orchestrator-ui.png` is the only screenshot captured so far, and it shows
the pre-rewrite interface. The views below are worth capturing against the
current UI; drop them in this directory and link them from the
[Screenshots section](../../README.md#screenshots) of the root README.

| Filename | What to capture |
| --- | --- |
| `workspace-dark.png` | Full window, dark theme: collections tree expanded, a request loaded, a successful response with highlighted JSON |
| `workspace-light.png` | The same view in the light theme |
| `assertions.png` | Response panel on the Assertions tab, with a mix of passing and failing results |
| `environments.png` | The environment editor modal with several variables |
| `chaining.png` | Extract tab showing a captured value, next to the environment that now holds it |
| `history.png` | Sidebar History pane with several runs, including a failure |

Aim for a viewport around 1440×900, and use a public API such as
`https://jsonplaceholder.typicode.com` so nothing private ends up in the frame.
